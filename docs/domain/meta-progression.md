# Meta progression

Terms as in the [glossary](glossary.md).

## Upgrades

Coins buy permanent upgrades between runs.

| Upgrade | Effect per upgrade level |
| --- | --- |
| Starting squad | +1 cat at the start of every run |
| Base damage | Higher yarn ball damage at the start of every run |
| Base fire rate | Faster firing at the start of every run |
| Coin bonus | More coins earned |

- Each upgrade's price rises about 1.4× per upgrade level. Example: an upgrade that costs 100 coins costs about 140 at the next level.
- An upgrade can be bought only with enough coins; buying it subtracts its price.

## Saved progress

- Progress (coins, upgrade levels, levels reached, stars, settings) is kept in the player's browser.
- Clearing the browser data resets progress. There is no cloud save in the MVP.
- Progress from an older game version is carried over to the new one.
